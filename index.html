BEHIND THE PROJECT

About GreekQuiz.

A small learning idea, developed into a real web application.

From desktop to the browser

GreekQuiz began as a Python/Tkinter vocabulary trainer in 2025. GreekQuiz 2.0 brings its vocabulary, categories, pronunciation support, and quiz feedback into the browser and integrates a separate linguistic pilot for Modern Greek morphology and grammar.

Why the linguistic architecture matters

Vocabulary data, grammatical paradigms, quiz logic, and interface code are kept separate. Only explicitly reviewed or reference-verified inflected forms may be used in grammar exercises. This avoids pretending that generated forms have been verified.

Project & learning

Created as an educational project for FH JOANNEUM. The interface is in English; vocabulary and linguistic answers remain in Greek and German. The site works without user accounts. Session progress can be saved locally in your browser.

Vocabulary recordings reproduce the original German answer audio. They are not recordings of Greek pronunciation.
